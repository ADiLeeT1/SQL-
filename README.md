# Самостоятельное задание 2 — БД сервиса доставки еды

Кулибаев Адилет, группа 24.246. PostgreSQL 14+ (проверено на 16.15).

## Файлы

| Файл | Что внутри | Часть задания |
|---|---|---|
| `design.md` | Сущности, атрибуты, связи, нормализация, ER-диаграмма | Часть 1 |
| `schema.sql` | ENUM-типы, 12 таблиц, CHECK, FK, COMMENT, индексы | Части 2 и 5.1 |
| `triggers.sql` | Обязательные триггеры 1–3, Вариант A, промокоды, статистика курьера | Часть 3 |
| `data.sql` | Тестовые данные: 6 ресторанов, 38 блюд, 10 клиентов, 6 курьеров, 26 заказов, 17 отзывов | — |
| `queries.sql` | 9 запросов | Часть 4 |
| `optimization.md` | EXPLAIN ANALYZE до/после индексов, выводы | Часть 5.2 |
| `perf_data.sql` | Генератор нагрузочных данных (300 000 заказов) для Части 5 | Часть 5.2 |
| `tests.sql` | Проверка триггеров: ошибочные операции и ожидаемые сообщения | доп. |

## Запуск

```bash
createdb food_delivery
psql -d food_delivery -f schema.sql
psql -d food_delivery -f triggers.sql
psql -d food_delivery -f data.sql
psql -d food_delivery -f queries.sql
psql -d food_delivery -f tests.sql      # необязательно
```

Все файлы можно запускать повторно: `schema.sql` удаляет старые объекты, `data.sql` очищает таблицы.

## Бонусы

- **Промокоды и скидки** — таблица `promo_codes`, триггер `trg_apply_promo` (срок, активность, лимит использований, минимальная сумма).
- **История цен** — `order_items.price_at_order`: цена фиксируется в момент заказа (в `data.sql` Лагман подорожал с 2500 до 2700 ₸, старые заказы сохранили 2500).
- **Оформление** — комментарии к каждой таблице, колонке, триггеру и запросу.
